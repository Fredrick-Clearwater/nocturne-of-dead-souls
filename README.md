# 《死魂灵的夜曲》· 规则分享站

一款狼人杀 Like 桌游规则集。核心机制「白昼回归迷雾」：所有复活 / 回归都推迟到第二天白天才生效，而且只报名字、不报原因——回归名单里的人，是好人也可能是狼。

## 在线浏览

- **分享版（推荐先看）**：`index.html` — 单文件规则页，可直接打印 / 存 PDF。
- **规则模拟器（导演台）**：`死魂灵的夜曲_模拟器_导演台.html` — 规则引擎 + 剧院风 UI，支持手动对局 / AI 批量推演 / 配置与统计。旧版 `死魂灵的夜曲_模拟器_V4.3新版.html` 保留存档。
- **主持人速查卡**：`死魂灵的夜曲_主持人速查卡.html` — 主持人的一页纸，可打印。

## 版本差异速览

- **V4.3（屠城阈值版）**：狼胜 = 场上人类 ≤ 死亡阵营人数；含「夜祷」一次转化；水妖 3 次复活；米提亚双查 + 降临者昼间指认（成功得一次性最高优先飞刀，双魂灵出局后刺中死神 = B3 终结）。
- **V4.2（屠边版）**：狼胜 = 5 神职全出局 或 3 普通人全出局；无夜祷；水妖 2 次复活。

其余配置、角色、回归迷雾、领袖、击杀优先级、遗言规则两版一致。

## 致谢 · 灵感来源

标题与核心意象致敬《原神》7.0 剧情第二幕《死魂灵的夜曲》。那一段精妙绝伦的故事里，暴风雪夜，科洛列夫茨基剧院，步步紧逼的黑雾，结局的惊天反转，正是我用「白昼回归迷雾」想去还原的东西。感谢米哈游与编剧团队贡献的绝妙演出！
