# 《死魂灵的夜曲》· 规则分享站

一款狼人杀 Like 桌游的规则集，核心机制为「白昼回归迷雾」——一切复活 / 回归都推迟到第二天白天生效，且不报原因，制造极致的身份迷雾。

本仓库由 WorkBuddy 生成并托管于 GitHub Pages。

## 在线浏览

- **分享版（推荐先看）**：`index.html` — 暗黑哥特风、单文件、可直接打印 / 存 PDF，方便发给朋友。
- **规则模拟器**：`死魂灵的夜曲_模拟器_V4.3新版.html` — 手动对局（上帝视角）+ 随机基准批量推演，观测规则骨架平衡趋势。
- **主持人速查卡**：`死魂灵的夜曲_主持人速查卡.html` — 一页纸可打印速查。

## 版本差异速览

- **V4.3（屠城阈值版）**：狼方胜利 = 场上人类 ≤ 死亡阵营人数；含「夜祷」一次性转化机制；水妖 3 次复活；米提亚双查 + 降临者昼间指认（成功得一次性最高优先飞刀，双魂灵出局后刺死神明＝ B3 终结）。
- **V4.2（屠边版）**：狼方胜利 = 5 神职全出局 或 3 普通人全出局；无夜祷；水妖 2 次复活。

其余配置、角色、回归迷雾、领袖、击杀优先级、遗言规则两版完全一致。
